# Unit IV: N-Queens using Backtracking

## Run
Start `node serve.js` at the repository root, then visit `http://127.0.0.1:8765/Unit4_Backtracking/`.

## Algorithm
Place one queen in each row and track occupied columns and diagonals. Conflicting partial boards are rejected; failed choices are undone.

## Prompt
See [Prompt.txt](Prompt.txt).

## Learning outcome
Understand recursive state-space search, constraint checks, and backtracking.
