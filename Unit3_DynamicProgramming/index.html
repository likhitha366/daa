Unit III · Dynamic Programming

Traveling Salesperson DP

Find an optimal round trip from city A using Held–Karp subset dynamic programming. Enter a square matrix of non-negative distances.

Optimal result and DP states

Enter a distance matrix and run the DP.

Algorithm idea

A state is a visited-city subset plus its endpoint. Append one city to the best smaller-subset path. Complexity is O(n²2ⁿ) time and O(n2ⁿ) space.
