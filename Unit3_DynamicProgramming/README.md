# Unit III: Traveling Salesperson with Dynamic Programming

## Run
Start `node serve.js` at the repository root, then visit `http://127.0.0.1:8765/Unit3_DynamicProgramming/`.

## Algorithm
Held–Karp stores the minimum path cost for each subset of cities and endpoint, then reconstructs the cheapest full tour back to A. The exact demo accepts 2–12 cities.

## Prompt
See [Prompt.txt](Prompt.txt).

## Learning outcome
Observe how subset states avoid recomputing partial tours.
