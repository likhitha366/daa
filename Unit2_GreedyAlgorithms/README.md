# Unit II: Greedy Job Sequencing

## Run
Start `node serve.js` at the repository root, then visit `http://127.0.0.1:8765/Unit2_GreedyAlgorithms/`.

## Algorithm
Sort unit-time jobs by profit, then place each into the latest open slot no later than its deadline. The output lists the schedule, placement decisions, and total profit.

## Prompt
See [Prompt.txt](Prompt.txt).

## Learning outcome
See how the greedy choice preserves earlier slots while maximizing profit for this job sequencing model.
