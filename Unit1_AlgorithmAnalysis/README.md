# Unit I: Sorting Complexity Visualizer

## Run
Start the repository server with `node serve.js` and visit `http://127.0.0.1:8765/Unit1_AlgorithmAnalysis/`.

## Algorithm
The activity counts key comparisons made by Merge Sort, Quick Sort, and Insertion Sort on identical input arrays. Input size and ordering can be changed interactively.

## Prompt
See [Prompt.txt](Prompt.txt).

## Learning outcome
Compare operation counts with the asymptotic growth of three sorting algorithms.
